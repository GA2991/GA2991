## Germán

Desarrollo videojuegos en Unity y herramientas para producción musical.

Actualmente trabajo en **Low-res Simulation**, un juego 3D en primera persona con estética PS1 (Unity, URP), con una demo prevista para finales de 2026.

**Tecnologías:** C#, JavaScript, Python, C++, Unity, Node.js

### Proyectos

**Audio y música**

- [vst-library-fx-advisor](https://github.com/GA2991/vst-library-fx-advisor): aplicación local para Windows que escanea plugins VST, los clasifica y propone cadenas de efectos.
- [ArduinoMidi](https://github.com/GA2991/ArduinoMidi): firmware para usar una placa Arduino como controlador MIDI (12 entradas digitales y 8 analógicas).
- [Musical-Timer](https://github.com/GA2991/Musical-Timer): recordatorio de pausas activas cada 45 minutos con música de tu biblioteca.

**Videojuegos**

- [Asteroid-Rain-Game](https://github.com/GA2991/Asteroid-Rain-Game): juego arcade de asteroides en Unity.
- [Low-Res-Chronicles-Scripts](https://github.com/GA2991/Low-Res-Chronicles-Scripts): scripts del primer prototipo de Low-res Simulation.
- [LowPolyCollectionLite](https://github.com/GA2991/LowPolyCollectionLite): colección de assets low poly para Unity.
